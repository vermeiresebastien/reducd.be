Firebase setup

Configureer eerst je Firebase-project voordat je kunt inloggen.

  1. Maak een project op console.firebase.google.com
  2. Authentication → Google sign-in inschakelen
  3. Firestore Database aanmaken
  4. Rules uit firestore.rules plakken
  5. Web-app config kopiëren naar js/firebase-config.js
  6. Zet jouw e-mail in REDUCD_ADMIN_EMAILS
  7. Verplicht: Firestore collection admins → document-ID = jouw e-mail (lowercase), bv. info@reducd.be (leeg document volstaat)
